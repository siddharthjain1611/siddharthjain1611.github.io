## Portfolio of Work (4 Case Studies)

### 1. Dynamic Geofencing & Pre-emptive Routing (Logistics/Marketplace)
- **Problem:** Surge pricing is reactive; 22% zero-dispatch rate during peak hours
- **Solution:** H3 hexagonal grid (Uber's library) + gradient-boosted demand forecast (T+25 min) + Global Supply Optimizer running every 90 seconds
- **Impact:** −18% zero-dispatch rate, P80 pickup 24→16 min, −12% empty-leg trips

### 2. Multi-Agent Evaluation Frameworks (AI Infrastructure)
- **Problem:** LLM support agents hallucinate policy violations; 17% violation rate with prompt-stuffing
- **Solution:** Parallel Shadow-Evaluator architecture via MCP Server — Primary Agent + Evaluator Agent with intercept gate
- **Impact:** 99% policy violation block rate, P90 latency +16% (1,050ms), zero policy rules in prompts

### 3. Privacy-Preserving Propensity Scoring (Ad-Tech/Data)
- **Problem:** Third-party cookie deprecation + stale purchase history signals
- **Solution:** In-session behavioral DNN (scroll depth, dwell time, interaction patterns) — zero persistent identifiers, fully cookie-free
- **Impact:** +22% CTR lift, +9% ROAS, GDPR/CCPA compliant

### 4. Bridging the Offline-Online Intent Gap (Consumer 0-to-1)
- **Problem:** 63% of high-AOV customers research online then visit stores, but salespeople start cold
- **Solution:** Encrypted QR handshake transferring full digital session context (3D layout, cart, fabric preferences) to salesperson's tablet in 1.5 seconds
- **Impact:** +34% in-store close rate (52% vs 31%), +18% AOV premium (₹3.9L vs ₹3.2L)
